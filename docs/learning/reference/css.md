## 0. 書き方の基本

```css
header h1 {
  color: #5EEAD4;
  font-size: 1.75rem;
}
```

| 部分 | 例 | 意味 |
|---|---|---|
| セレクタ | `header h1` | どの要素に当てるか |
| プロパティ | `color` | 何を変えるか |
| 値 | `#5EEAD4` | どう変えるか |
| 宣言 | `color: #5EEAD4;` | プロパティと値の組。`:` のあとに空白1つ、最後に `;` |
| ルール | セレクタ ＋ `{ }` 全体 | ルールとルールの間は1行空ける。ページの上から順に並べると探しやすい |

- **知らないプロパティやつづりの間違いがあっても、エラーにならずその行が無視される**（例：`font-coler`）。開発者ツールの Styles 欄では取り消し線と ⚠ がつき、VS Code では波線が出る
- `Shift + Option + F` で VS Code が書き方（空白、字下げ）をそろえてくれる

### CSS を当てる方法
| 方法 | 書き方 | 使いどころ | 使った |
|---|---|---|---|
| 別のファイル | `<head>` に `<link rel="stylesheet" href="style.css">` | 普通はこれ。複数のページで同じ CSS を使える | ✅ |
| `<style>` 要素 | `<head>` の中に CSS を直接書く | 1ページだけのちょっとした確認 | |
| `style` 属性 | `<p style="color: red;">` | ほぼ使わない。HTML と見た目が混ざる | |

## 1. セレクタ

| セレクタ | 書き方 | 当たるもの | 使った |
|---|---|---|---|
| 要素 | `body` | すべての `<body>` | ✅ |
| class | `.done` | `class="done"` がついた要素（何個でも） | ✅ |
| id | `#todo` | `id="todo"` の要素（1つだけ） | |
| 子孫 | `header h1` | `<header>` の中にある `<h1>` | ✅ |
| 子孫（class ＋ 要素） | `.done label` | `class="done"` の要素の中にある `<label>` | ✅ |
| すぐ隣 | `input:checked + label` | チェックが入った `<input>` のすぐ次の `<label>` | |
| 複数まとめて | `h1, h2` | `<h1>` と `<h2>` の両方 | |
| すべて | `*` | すべての要素 | ✅（`box-sizing`） |
| 属性 | `input[type="checkbox"]` | `type` 属性が `checkbox` の `<input>` | |

### 状態のセレクタ（要素のうしろにつける）
| セレクタ | 当たるとき | 使った |
|---|---|---|
| `:hover` | マウスが乗っているとき | ✅ |
| `:focus-visible` | キーボード（Tab キー）で選ばれているとき | |
| `:focus` | 選ばれているとき（クリックでもキーボードでも） | ✅ |
| `:active` | 押している最中 | |
| `:checked` | チェックが入っているとき | |
| `:disabled` | `disabled` がついているとき | |

### class の使い方
- 見た目を変えるときは、**基本は class を使う**。id は JS やラベルのために使う
- 1つの要素に複数つけるときは、空白で区切る：`class="done urgent"`
- **名前は「見た目」ではなく「状態・役割」でつける**：`done`、`delete-button`（○）／ `gray-line`、`red-button`（×）。デザインを変えても HTML を直さずに済む

### 継承と優先順位
- **継承**：文字に関するプロパティ（`color`、`font-family`、`font-size` など）は、親に当てると子・孫に引き継がれる。箱に関するプロパティ（`background-color`、`border` など）は引き継がれない
- **継承しない例外**：`<a>`、`<button>`、`<input>` はブラウザが最初から色や文字を決めているので、親の `color` などを引き継がない。変えたいときは直接書く
- **直接書いたほうが勝つ**：親から引き継いだ値より、その要素に直接当てた値が優先される。開発者ツールの Styles 欄では、負けた値に取り消し線がつく
- **詳細度**：同じ要素に当たる2つのルールで、同じプロパティの値がぶつかったときは、より詳しく指定したほうが勝つ。だいたい id ＞ class ＞ 要素 の順に強く、数が多いほど強い。同じ強さなら**あとに書いたほう**が勝つ
- **ブラウザの初期設定**（user agent stylesheet）：`body` の `margin: 8px`、`h1` の上下の余白、`ul` の左の `padding: 40px` など。ブラウザごとに少し違うので、自分で `0` にしてから決め直すことが多い（リセット CSS）

## 2. 文字

| プロパティ | 意味 | 例 | 使った |
|---|---|---|---|
| `color` | 文字の色（`font-color` や `text-color` ではない） | `#E2EBE8` | ✅ |
| `font-family` | フォント。左から順に試し、最後に総称を書く | `"Noto Sans JP", "Hiragino Sans", sans-serif` | ✅ |
| `font-size` | 文字の大きさ | `1.75rem` | ✅ |
| `font` | 文字の設定（大きさ・フォント・太さなど）をまとめて指定。`font: inherit` で親と同じにする（`<input>` や `<button>` に必要） | `inherit` | ✅ |
| `font-weight` | 太さ | `400`（標準）、`700`（太字）、`bold` | ✅ |
| `letter-spacing` | 文字と文字の間隔 | `0.02em` | ✅ |
| `line-height` | 行の高さ（行間）。単位なしで書くと「文字の大きさの何倍か」 | `1.6` | |
| `text-align` | 文字のそろえ方 | `left`、`center`、`right` | |
| `text-decoration` | 文字につける線 | 下の表 | ✅ |
| `text-decoration-color` | 線の色 | `#8FA59F` | |

### フォントの総称
| 総称 | 見た目 | 日本語でいうと |
|---|---|---|
| `sans-serif` | 線の太さが一定 | ゴシック体（画面ではこれがよく使われる） |
| `serif` | 線の端に飾りがある | 明朝体 |
| `monospace` | 1文字の幅がすべて同じ | コードを書くときのフォント |
| `system-ui` | OS の標準フォント | Mac ならヒラギノなど |

名前に空白が入るフォントは `"` で囲む。パソコンに入っていないフォントは飛ばされる（`"Noto Sans JP"` は Mac に最初は入っていない）。

### `text-decoration` の値
| 値 | 見た目 | よく使う場所 | 使った |
|---|---|---|---|
| `line-through` | 取り消し線 | 完了したもの、値下げ前の価格 | ✅ |
| `underline` | 下線 | リンク | |
| `none` | 線なし | リンクの下線を消すとき | |

## 3. 色

| 書き方 | 例 | 特徴 |
|---|---|---|
| 色の名前 | `white`、`navy`、`tomato`、`transparent`（透明） | わかりやすいが、細かい色は選べない |
| 16進数のコード | `#5EEAD4`、`#333` | いちばんよく使う。`#rrggbb` で赤・緑・青を `00`〜`ff`。3つが近いほど灰色。`#333` は `#333333` の省略 |
| `rgb()` | `rgb(94, 234, 212)` | 赤・緑・青を 0〜255 で書く |
| `hsl()` | `hsl(171, 77%, 64%)` | 色相・彩度・明るさで書く。「同じ色で少し明るく」を作りやすい |

- 文字と背景のコントラスト比は **4.5 以上**が目安。開発者ツールの Styles 欄で色の四角をクリックすると「Contrast ratio」が出る
- 真っ白の背景に真っ黒の文字（またはその逆）は、まぶしく目が疲れやすい。少しずらす

## 4. 単位

| 単位 | 意味 | よく使う場所 | 使った |
|---|---|---|---|
| `px` | 画面上の点の数（固定） | 枠線の太さ（`1px`）、角の丸み、余白 | ✅ |
| `rem` | ページの基準の文字の大きさ（既定 16px）の何倍か。ユーザーがブラウザで文字を大きくすると一緒に大きくなる | 文字の大きさ、余白 | ✅ |
| `em` | その要素（または親）の文字の大きさの何倍か | 文字に合わせて変えたい間隔 | ✅（`letter-spacing`） |
| `%` | 親の大きさの何割か | 幅 | ✅（`width: 100%`） |

## 7. ボックスモデル（箱の4つの層）

```
margin（外側の余白：隣の箱との間）
└ border（枠線）
  └ padding（内側の余白：枠線と中身の間）
    └ content（中身：width / height）
```

| プロパティ | 意味 | 使った |
|---|---|---|
| `width` / `height` | 中身の幅・高さ | ✅ |
| `max-width` | 幅の上限。画面が広くてもこれ以上広がらない | ✅ |
| `padding` | 内側の余白 | ✅ |
| `margin` | 外側の余白。左右を `auto` にすると中央に寄る（`margin: 0 auto`） | ✅ |
| `box-sizing` | `border-box` にすると、`width` に padding と border が含まれる。ファイルの最初に `*, *::before, *::after { box-sizing: border-box; }` と書くのが決まり文句 | ✅ |

### 値の書き方（`margin` も `padding` も同じ）
| 書き方 | 意味 |
|---|---|
| `16px` | 上下左右 |
| `32px 16px` | 上下、左右 |
| `8px 16px 32px` | 上、左右、下 |
| `8px 16px 32px 4px` | 上・右・下・左（時計回り） |
| `margin-top: 8px` | 1か所だけ（`-top` `-right` `-bottom` `-left`） |

開発者ツールの Elements → **Computed** タブで、箱の4つの層と数字が見られる。

## 8. 並び方（`display`）

| 種類 | 並び方 | 幅 | 例 |
|---|---|---|---|
| ブロック（`block`） | 縦に積まれる | 親の幅いっぱい | `<div>` `<p>` `<h1>` `<ul>` `<li>` `<form>` |
| インライン（`inline`） | 文字のように横に並ぶ。幅や上下の余白は効かない | 中身の分 | `<span>` `<a>` `<label>` `<strong>` |
| インラインブロック（`inline-block`） | 横に並ぶが、箱として幅や余白を持てる | 中身の分 | `<input>` `<button>` |
| `flex` | 子を Flexbox で並べる | | |
| `grid` | 子を縦横のマス目で並べる（表のような配置） | | |
| `none` | 表示しない | | |

## 9. Flexbox

親に `display: flex;` と書くと、**直接の子**が横一列に並ぶ。

| プロパティ（親に書く） | 意味 | よく使う値 | 使った |
|---|---|---|---|
| `display` | Flexbox を使う | `flex` | ✅ |
| `gap` | 子と子の間隔 | `8px` | ✅ |
| `flex-direction` | 並べる向き | `row`（横。初期値）、`column`（縦） | ✅ |
| `align-items` | 並べる向きと**直角**のそろえ方（横並びなら縦） | `center`、`flex-start`、`flex-end` | ✅ |
| `justify-content` | 並べる向きのそろえ方（横並びなら横） | `flex-start`、`center`、`space-between` | |
| `flex-wrap` | 入りきらないとき折り返す | `wrap` | ✅ |

| プロパティ（子に書く） | 意味 | よく使う値 | 使った |
|---|---|---|---|
| `flex` | 余った幅をどれだけもらうか | `1` | ✅ |
| `flex-basis` | 最初の幅。`100%` にすると1行を使い切る | `100%` | ✅ |

## 10. メディアクエリ（画面の幅で切り替える）

```css
@media (max-width: 480px) {
  form {
    flex-wrap: wrap;
  }
}
```

| 条件 | 意味 |
|---|---|
| `(max-width: 480px)` | 幅が 480px 以下のとき（スマホ向けに上書きする） |
| `(min-width: 768px)` | 幅が 768px 以上のとき（スマホを基本にして広い画面向けを足す＝モバイルファースト） |

- 切り替える幅を**ブレークポイント**と呼ぶ。スマホ 480px 以下、タブレット 768px 前後がよく使われる
- 外のルールを上書きするので、ファイルの**いちばん下**に書く
- `<head>` の `<meta name="viewport" content="width=device-width, initial-scale=1.0">` がないと、スマホはパソコン用の幅（約 980px）で描いて縮小するので、メディアクエリも効かず文字も小さくなる
- 開発者ツールで `Cmd + Shift + M` を押すと、スマホの幅で表示できる

## 11. CSS の整理のしかた

| 方法 | 内容 | 使った |
|---|---|---|
| ページの順に並べる＋区切りのコメント | `/* ===== フォーム ===== */` のように区画ごとにまとめる | |
| CSS の入れ子（ネスト） | ルールの中にルールを書ける（2023年ごろから主要なブラウザで使える）。深くしすぎると詳細度が上がって上書きしにくくなるので、2〜3段まで | |
| Sass（SCSS） | 入れ子や変数を使える CSS の拡張。ブラウザは読めないので、CSS に変換してから使う | |
| CSS 変数 | `--accent: #5EEAD4;` と決めて `var(--accent)` で使う。色を1か所で変えられる | |
| 命名のルール（BEM など） | `todo-list__item--done` のように、class 名で階層と状態を表す | |
