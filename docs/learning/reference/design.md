# デザインの値（ToDo アプリ）

作成: 2026-10-06（ステップ2）
色・大きさなどデザインの値は Claude が提案し、学習者が CSS に書く。テーマはダークモード。

## 色
テーマ：黒にほんのり緑を混ぜた背景 ＋ ティール（水色寄りの緑）のアクセント。2026-10-06 に2案（ティール／ミント）から学習者が選んだ。

| 役割 | 色 | 使う場所 | 背景とのコントラスト比 |
|---|---|---|---|
| 背景 | `#121615` | ページ全体（`body`） | |
| 面 | `#1C2321` | 入力欄、ToDo の1件ごとの箱など、背景より一段明るくしたいところ | |
| 枠線 | `#3A4744` | 入力欄やボタンの枠、区切り線 | |
| 文字 | `#E2EBE8` | 普通の文字 | 15.0 |
| 薄い文字 | `#8FA59F` | 完了した ToDo、期限、placeholder、件数などの補足 | 7.0 |
| アクセント | `#5EEAD4` | アプリ名、追加ボタン、チェック済みのチェックボックス、選択中の入力欄の枠 | 12.3 |
| アクセントの上の文字 | `#0F1F1C` | 追加ボタンのように、アクセント色を背景に使うときの文字 | 11.5（アクセントの上で） |
| 危険 | `#F28B82` | 削除ボタン | 7.6 |

- 暗い背景の上では、真っ白や濃い原色は避け、少し淡い色を使う（まぶしさを抑え、コントラストを保つ）
- 文字と背景のコントラスト比は 4.5 以上を目安にする（開発者ツールの色を選ぶ画面で確かめられる）
- 使う色はこの表の中だけにする（色が増えるとまとまりがなくなる）

## 文字の大きさ
| 役割 | 大きさ |
|---|---|
| アプリ名（`h1`） | `1.75rem`（28px）、太さ `700`、文字の間隔 `0.02em` |
| 普通の文字 | `1rem`（16px。ブラウザの既定） |
| 補足（期限、件数） | `0.875rem`（14px） |

- `rem` = ページの基準の文字の大きさ（既定 16px）の何倍か。ユーザーがブラウザで文字を大きくする設定にしたとき、それに合わせて大きくなるので、文字の大きさには `px` より `rem` を使う

## ログインの画面とユーザーの帯（ステップ7、7-6）
色は上の表の中から使う。

| 場所 | 値 | 理由 |
|---|---|---|
| 見出し（`h2`） | `1.25rem`、太さ `700`、文字の色、余白 `0 0 16px` | アプリ名（`1.75rem`）より一段小さく |
| ログインのフォーム | 縦に並べる（`flex-direction: column`、`align-items: stretch`）、間 `12px`、入力欄は幅 `100%` | 入力欄が2つだけなので、縦に並べて広く使う |
| 主のボタン（ログイン） | 今の「追加する」と同じ（アクセントで塗る） | 一番押してほしいボタン |
| 二番目のボタン（登録する） | 背景 `transparent`、文字と枠 アクセント `#5EEAD4` | 塗らないことで「主」と区別する |
| エラー文 | 危険 `#F28B82`、`0.875rem`、余白 `0`、`min-height: 1.25em` | 文が出たときに下のボタンが動かないよう、高さを先に取っておく |
| ユーザーの帯 | 横に並べて両端に寄せる（`justify-content: space-between`、`align-items: center`）、下の余白 `16px` | 左にメールアドレス、右にログアウト |
| メールアドレス | 薄い文字 `#8FA59F`、`0.875rem` | 補足の情報 |
| ログアウトボタン | 背景 `transparent`、文字 `#E2EBE8`、枠 `#3A4744`、角 `6px`、余白 `4px 12px`、`0.875rem`。マウスを乗せたら文字と枠をアクセント | 目立たせすぎない（危険の色にしない。ログアウトは消える操作ではない） |
| `[hidden]` | `display: none !important` | `hidden` 属性は、CSS で `display` を指定した要素には効かなくなる。その場合も確実に隠すため |
