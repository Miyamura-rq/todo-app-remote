# デザインの値（ToDo アプリ）

作成: 2026-10-06（ステップ2）
色・大きさなどデザインの値は Claude が提案し、学習者が CSS に書く。テーマはダークモード。

## 色
| 役割 | 色 | 使う場所 |
|---|---|---|
| 背景 | `#202124` | ページ全体（`body`） |
| 面 | `#303134` | 入力欄、ToDo の1件ごとの箱など、背景より一段明るくしたいところ |
| 枠線 | `#5F6368` | 入力欄やボタンの枠、区切り線 |
| 文字 | `#E8EAED` | 普通の文字 |
| 薄い文字 | `#9AA0A6` | 完了した ToDo、期限、placeholder、件数などの補足 |
| アクセント | `#8AB4F8` | アプリ名、追加ボタン、選択中の入力欄の枠 |
| 危険 | `#F28B82` | 削除ボタン |

- 暗い背景の上では、真っ白や濃い原色は避け、少し淡い色を使う（まぶしさを抑え、コントラストを保つ）
- 文字と背景のコントラスト比は 4.5 以上を目安にする（開発者ツールの色を選ぶ画面で確かめられる）

## 文字の大きさ
| 役割 | 大きさ |
|---|---|
| アプリ名（`h1`） | `1.75rem`（28px） |
| 普通の文字 | `1rem`（16px。ブラウザの既定） |
| 補足（期限、件数） | `0.875rem`（14px） |

- `rem` = ページの基準の文字の大きさ（既定 16px）の何倍か。ユーザーがブラウザで文字を大きくする設定にしたとき、それに合わせて大きくなるので、文字の大きさには `px` より `rem` を使う
