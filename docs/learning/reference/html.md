# HTML の要素と属性（早見表）

作成: 2026-10-06（ステップ2）
詳しく調べるとき: [MDN の HTML 要素リファレンス](https://developer.mozilla.org/ja/docs/Web/HTML/Element)

各表の「よく使う」欄の印：◎ = ToDo アプリで使う、○ = よく見かける、△ = 知っておけば十分

---

## 0. 書き方の基本

```html
<a href="https://example.com">例のサイト</a>
```

| 用語 | 例では | 意味 |
|---|---|---|
| 開始タグ | `<a href="https://example.com">` | 要素の始まり。属性はここに書く |
| 終了タグ | `</a>` | 要素の終わり |
| 要素 | 全体 | 画面の部品1つ分 |
| 属性 | `href="https://example.com"` | 要素につける追加の情報。`名前="値"` の形 |
| 中身 | `例のサイト` | タグにはさまれた部分。別の要素を入れてもよい（入れ子） |
| 空要素 | `<br>`、`<img>`、`<input>`、`<meta>` | 中身を持たないので終了タグがない |

- **コメント**：`<!-- ここは画面に出ない -->`。メモや、一時的に要素を隠したいときに使う
- **特別な文字**：`<` や `&` をそのまま画面に出したいときは、`&lt;`（<）、`&gt;`（>）、`&amp;`（&）と書く。そのまま書くと、タグの始まりと間違えられる
- HTML は間違いがあってもエラーを出さず、ブラウザが何とか表示しようとする。おかしいと思ったら、開発者ツールの **Elements** タブで「ブラウザが実際に作った形」を確かめる

## 1. ページ全体の形と `<head>` の中身

| 要素 | 意味・使いどころ | よく使う属性 | よく使う |
|---|---|---|---|
| `<!DOCTYPE html>` | 「これは HTML です」という宣言。ファイルの1行目に書く（要素ではない） | | ◎ |
| `<html>` | いちばん外側の要素。全部をこの中に入れる | `lang="ja"`（ページの言語） | ◎ |
| `<head>` | ページの情報。画面には出ない | | ◎ |
| `<body>` | 画面に出る中身 | | ◎ |
| `<meta>` | ページの設定。`<head>` の最初に文字コードを書く | `charset="UTF-8"`、`name="viewport"`（スマホ向けの設定） | ◎ |
| `<title>` | ブラウザのタブや、検索結果に出るタイトル | | ◎ |
| `<link>` | 外のファイルを読み込む。CSS の読み込みに使う | `rel="stylesheet"`、`href="style.css"` | ◎（2-3） |
| `<script>` | JavaScript を読み込む・書く | `src="app.js"`、`defer` | ◎（ステップ3） |
| `<style>` | CSS を HTML の中に直接書く（普通は別ファイルにする） | | △ |

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>ページのタイトル</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    （画面に出る中身）
  </body>
</html>
```
VS Code では、`.html` ファイルで `!` → `Tab` と押すと、この形のひな形が入る（Emmet）。`lang="en"` は `ja` に変える。

## 2. ページの区画

ページをいくつかの「場所」に分ける要素。見た目は何も変わらないが、構造が伝わる。

| 要素 | 意味・使いどころ | よく使う |
|---|---|---|
| `<header>` | ページ（または区画）の上部。サイト名、ロゴ、メニューなど | ◎ |
| `<nav>` | 主なリンクの集まり（メニュー） | ○ |
| `<main>` | ページの主な内容。1ページに1つだけ | ◎ |
| `<section>` | テーマごとのまとまり。普通は見出しを持つ（例：「未完了」「完了」） | ○ |
| `<article>` | それだけで完結する内容（ブログの1記事、1件の投稿など） | ○ |
| `<aside>` | 本文とは別の補足（サイドバー、関連リンク） | △ |
| `<footer>` | ページ（または区画）の下部。著作権、問い合わせ先、件数など | ◎ |
| `<div>` | **意味を持たない**箱。CSS でまとめて見た目を変えたいときなど、合う要素がないときに使う | ○ |

```html
<body>
  <header>
    <h1>サイト名</h1>
    <nav>…</nav>
  </header>
  <main>
    <section>
      <h2>お知らせ</h2>
      …
    </section>
  </main>
  <footer>© 2026</footer>
</body>
```

**選び方**：まず意味のある要素を探す → なければ `<div>`。`<div>` だらけのページは、読み上げソフトや後で読む人に構造が伝わらない。

## 3. 見出しと文章

| 要素 | 意味・使いどころ | よく使う |
|---|---|---|
| `<h1>`〜`<h6>` | 見出し。数字が小さいほど大きな見出し。`<h1>` はページの題名として1つ。**文字の大きさではなく、階層で選ぶ**（`<h2>` の下の小見出しは `<h3>`。番号を飛ばさない） | ◎ |
| `<p>` | 段落（文章のひとまとまり）。中に入れられるのは文章の中に入るもの（文字、`<a>`、`<strong>` など）だけで、`<ul>` や `<p>` は入れられない | ◎ |
| `<br>` | 文章の中での改行。住所、詩など。**段落を分けるためには使わない**（要素を分ける） | ○ |
| `<hr>` | 話題の区切り（横線が出る） | △ |
| `<strong>` | 重要な部分（太字になる） | ○ |
| `<em>` | 強調して読む部分（斜体になる）。`<strong>` は「重要」、`<em>` は「声に出すとき強める」 | △ |
| `<span>` | 文章の一部を囲むだけの、意味を持たない要素。文章の中の一部だけ色を変えたいときなど | ○ |
| `<small>` | 注意書き、細かい文字 | △ |
| `<code>` | コードの一部 | △ |
| `<pre>` | 空白と改行を書いたとおりに表示する。`<code>` と組み合わせてコードを載せる | △ |
| `<blockquote>` | 他からの引用（長いもの） | △ |

**太字にしたいだけ**なら CSS を使う。`<strong>` は「重要」という意味をつけたいときに使う。HTML は意味、見た目は CSS、と分けるのが基本。

## 4. リスト

| 要素 | 意味・使いどころ | よく使う |
|---|---|---|
| `<ul>` | 順番に意味がないリスト（先頭に「・」が出る） | ◎ |
| `<ol>` | 順番に意味があるリスト（先頭に番号が出る）。手順、ランキングなど | ○ |
| `<li>` | リストの1項目。`<ul>` か `<ol>` の**直接の子**として使う。中には何を入れてもよい（チェックボックス、ボタンなど） | ◎ |
| `<dl>` `<dt>` `<dd>` | 用語と説明の組（`<dt>` = 用語、`<dd>` = 説明）。FAQ や「項目：値」の一覧 | △ |

```html
<ol>
  <li>材料を切る</li>
  <li>炒める</li>
</ol>

<dl>
  <dt>HTML</dt>
  <dd>画面の骨組みを書く言語</dd>
</dl>
```

メニュー（`<nav>` の中のリンク）も、リンクを `<ul>` と `<li>` で並べるのが一般的。

## 5. リンク・画像・埋め込み

| 要素 | 意味・使いどころ | よく使う属性 | よく使う |
|---|---|---|---|
| `<a>` | リンク | `href`（行き先）、`target="_blank"`（新しいタブで開く） | ◎ |
| `<img>` | 画像（空要素） | `src`（画像のファイル）、`alt`（画像の説明。必須）、`width` `height` | ○ |
| `<video>` / `<audio>` | 動画・音声 | `src`、`controls`（再生ボタンを出す） | △ |
| `<iframe>` | 別のページを埋め込む（YouTube、Google マップなど） | `src` | △ |

`href` の書き方：
| 書き方 | 意味 |
|---|---|
| `https://example.com` | 別のサイト |
| `about.html` | 同じフォルダの別のページ（相対パス） |
| `#contact` | 同じページの `id="contact"` の場所へ移動 |
| `mailto:xxx@example.com` | メールソフトを開く |

`alt` は、画像が表示されないときや、読み上げソフトが読むときに使われる。飾りだけの画像なら `alt=""`（空）にする。

## 6. 表

| 要素 | 意味・使いどころ | よく使う |
|---|---|---|
| `<table>` | 表全体 | ○ |
| `<caption>` | 表のタイトル。`<table>` のすぐ内側の最初に書く | △ |
| `<thead>` | 見出しの行のまとまり | ○ |
| `<tbody>` | データの行のまとまり | ○ |
| `<tfoot>` | 合計などの行のまとまり | △ |
| `<tr>` | 1行（table row） | ○ |
| `<th>` | **見出しのマス**（太字・中央ぞろえになる）（table header） | ○ |
| `<td>` | データのマス（table data） | ○ |

```html
<table>
  <caption>今週の ToDo</caption>
  <thead>
    <tr>
      <th>やること</th>
      <th>期限</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>牛乳を買う</td>
      <td>10/7</td>
    </tr>
  </tbody>
</table>
```

- マスをつなげる：`<td colspan="2">`（横に2マス）、`<td rowspan="2">`（縦に2マス）
- **表は「行と列のデータ」を見せるためだけに使う**。昔は画面のレイアウト（横に並べるなど）に表を使っていたが、今は CSS（Flexbox など、2-4）を使う

## 7. フォーム（入力）

| 要素 | 意味・使いどころ | よく使う属性 | よく使う |
|---|---|---|---|
| `<form>` | 入力のまとまり。中で Enter を押すと送信される | `action`（送り先）、`method`（`get` / `post`） | ◎ |
| `<label>` | 入力欄の名前。クリックすると入力欄が選ばれ、読み上げソフトにも伝わる | `for`（入力欄の `id`） | ◎ |
| `<input>` | 1行の入力欄など（空要素）。`type` で種類が変わる | 下の表 | ◎ |
| `<textarea>` | 複数行の入力欄 | `rows`、`placeholder` | ○ |
| `<select>` / `<option>` | 選択肢から選ぶ（プルダウン） | `value`、`selected` | ○ |
| `<button>` | ボタン | `type="submit"`（送信する。`<form>` の中での既定）、`type="button"`（何もしない。JS で動きをつける） | ◎ |
| `<fieldset>` / `<legend>` | 入力欄のグループと、その名前 | | △ |

**`<input>` の `type`（全22種類）**

`type` を書かないと `text` になる。ブラウザが知らない `type` を書いても、エラーにならず `text` として表示される。

文字を入力する
| type | 見た目・動き | よく使う |
|---|---|---|
| `text` | 1行の文字（既定） | ◎ |
| `password` | 入力した文字が伏せ字（●）になる | ○ |
| `email` | メールアドレス。送信時に形をチェックする。スマホでは `@` のあるキーボードが出る | ○ |
| `url` | URL。送信時に形をチェックする | △ |
| `tel` | 電話番号。スマホでは数字のキーボードが出る（形のチェックはしない） | △ |
| `search` | 検索欄。入力すると消去ボタン（×）が出るブラウザがある | △ |

数を入力する
| type | 見た目・動き | よく使う |
|---|---|---|
| `number` | 数字だけ。上下の矢印で増減できる。`min` `max` `step` で範囲と刻みを決める | ○ |
| `range` | スライダー。音量のように「だいたいの量」を選ぶ | △ |

日付・時刻を入力する
| type | 見た目・動き | よく使う |
|---|---|---|
| `date` | 年月日（カレンダーが出る） | ◎（期限をつけるなら） |
| `time` | 時刻（時・分） | ○ |
| `datetime-local` | 年月日と時刻 | ○ |
| `month` | 年と月 | △ |
| `week` | 年と週（Safari など、使えないブラウザがある） | △ |

選ぶ
| type | 見た目・動き | よく使う |
|---|---|---|
| `checkbox` | チェックボックス。オン／オフ、または複数選ぶ | ◎ |
| `radio` | ラジオボタン。同じ `name` の中から1つだけ選ぶ | ○ |
| `color` | 色を選ぶ（カラーピッカーが出る） | △ |
| `file` | ファイルを選ぶ（アップロード）。`accept="image/*"` で種類をしぼる | ○ |

ボタン・その他
| type | 見た目・動き | よく使う |
|---|---|---|
| `submit` | 送信ボタン。今は `<button type="submit">` を使うことが多い | △ |
| `reset` | 入力を最初の状態に戻すボタン。押し間違いで消えるので、あまり使わない | △ |
| `button` | 何もしないボタン（JS で動きをつける）。今は `<button type="button">` を使うことが多い | △ |
| `image` | 画像を送信ボタンにする | △ |
| `hidden` | 画面に出ない値。ユーザーに見せずに、一緒に送りたい値に使う（中身は開発者ツールで見えるので、秘密の値には使わない） | △ |

**チェックは補助だけ**：`email` などの形のチェックや `required` は、ブラウザ側の親切な機能。開発者ツールで簡単に外せるので、サーバー側でも必ず確かめる（ステップ8）。

**入力欄でよく使う属性**
| 属性 | 意味 |
|---|---|
| `id` | ページの中で1つだけの名前。`<label for>` と結びつける |
| `name` | 送信するときのデータの名前 |
| `value` | 値（最初に入っている文字、選んだときに送る値） |
| `placeholder` | 何も入力していないときに出る薄い文字（入力例） |
| `checked` | チェックが入った状態（checkbox / radio） |
| `required` | 入力必須にする |
| `disabled` | 使えなくする（グレーになる） |
| `maxlength` | 入力できる最大の文字数 |

```html
<form>
  <label for="email">メールアドレス</label>
  <input type="email" id="email" name="email" placeholder="you@example.com" required>
  <button type="submit">登録</button>
</form>
```

`checked`、`required`、`disabled` のように、**値を書かず名前だけ書く属性**もある（書いてあれば「オン」）。

## 8. 知っておくと便利な要素

| 要素 | 意味・使いどころ | よく使う |
|---|---|---|
| `<details>` / `<summary>` | クリックで開閉する部分（JS なしで動く）。FAQ など | ○ |
| `<dialog>` | ダイアログ（ポップアップの画面） | △ |
| `<template>` | 画面には出ない「型」。JS で複製して使う（ToDo の1行の型など、ステップ3で使うかもしれない） | △ |
| `<time>` | 日時。`datetime="2026-10-06"` で機械にも読める形を添える | △ |

## 9. どの要素にもつけられる属性

| 属性 | 意味 | 例 |
|---|---|---|
| `id` | ページの中で1つだけの名前。リンク先（`#id`）、`<label for>`、JS から探すときに使う | `id="todo-input"` |
| `class` | グループの名前。同じ class を何個つけてもよい。**CSS で見た目を変えるときの主役**（2-3） | `class="todo done"`（空白で区切って複数） |
| `hidden` | 隠す | |
| `title` | マウスを乗せたときに出る説明 | |
| `style` | その要素だけに CSS を直接書く（普通は使わず、CSS ファイルに書く） | |
| `data-*` | 自由に決めてよいデータ。JS から使う | `data-id="3"` |

**`id` と `class` の使い分け**：1つしかないもの → `id`、同じ種類のものが複数ある（ToDo の各行など） → `class`。

## 10. どの要素の中に何を入れてよいか

### 大まかなルール
要素は、大きく2種類に分かれる。

| 種類 | 例 | 中に入れてよいもの |
|---|---|---|
| **大きな部品**（ブロック的な要素） | `<div>` `<main>` `<section>` `<header>` `<footer>` `<form>` `<li>` `<td>` `<ul>` の外側など | 大きな部品も、小さな部品も入れてよい |
| **文章を入れる器** | `<p>` `<h1>`〜`<h6>` | 小さな部品だけ |
| **小さな部品**（文章の中に入る要素） | 文字、`<a>` `<strong>` `<em>` `<span>` `<br>` `<img>` `<input>` `<button>` `<label>` `<code>` | 小さな部品だけ |

覚え方：**「文章の中に入れて自然か」**で考える。`<p>` の中にリンクや太字は自然だが、箇条書きや別の段落は不自然 → 入れられない。

※ `<p>` の中に何も置けないわけではない。文字、`<a>`、`<strong>`、`<span>` などの小さな部品は入れてよい。

### 親子がセットで決まっているもの
| 親 | 直接の子にできるもの |
|---|---|
| `<html>` | `<head>` と `<body>` だけ |
| `<head>` | `<meta>` `<title>` `<link>` `<script>` `<style>` など（画面に出ないもの） |
| `<ul>` / `<ol>` | `<li>` だけ（文字や `<div>` を直接置かない） |
| `<table>` | `<caption>` `<thead>` `<tbody>` `<tfoot>` `<tr>` |
| `<tr>` | `<th>` と `<td>` だけ |
| `<select>` | `<option>` |
| `<dl>` | `<dt>` と `<dd>` |

### 入れてはいけない組み合わせ（よくある間違い）
- `<a>` や `<button>` の中に、`<a>` や `<button>`（クリックできるもの同士を入れ子にしない）
- `<form>` の中に `<form>`
- `<p>` の中に `<p>`、`<ul>`、`<div>`、`<h1>` など

### 迷ったときの確かめ方
1. **MDN で調べる**：各要素のページの「技術的概要」の表に、「許可されている内容」（中に入れてよいもの）と「許可されている親要素」が書いてある
2. **Elements タブで確かめる**：書いたとおりの形になっていなければ、ブラウザが直した＝ルール違反の可能性が高い
3. **チェッカーにかける**：[W3C の Nu HTML Checker](https://validator.w3.org/nu/) にファイルを貼り付けると、ルール違反を一覧で教えてくれる
