# D-0014 セッションの始めの3問をやめる

日付: 2026-10-13
置き換える決定: D-0002（セッションの始めの状況確認の部分だけ）

## 決定
- セッションの始めの3問（前回の振り返り／今日やりたいこと／詰まっていること）はしない。
- セッションの終わりの理解度チェックは続ける。
- D-0002 のそれ以外（ヒント3段階、レビュー、progress.md の4段階）は変わらない。

## 理由
- 学習者から「毎回聞かなくていい」と希望があった。
- 前回の状況は STATUS.md と progress.md で分かり、詰まっていることがあれば学習者から言える。

## 却下した案
- 3問を1問（今日やりたいこと）に減らす: 学習者は「聞かなくていい」と言っており、必要なら自分から伝えられるため。
