# D-0034 ★ の確かめ方（curl など）も Claude が実行して結果を見せる

日付: 2026-11-02
補足する決定: D-0030（★ の確かめ方は学習者が実行する、の部分を変える）。D-0023・D-0027 の「確かめ方は学習者が実行する」も、ステップ9 からはこれに従う

## 決定
- ★（学習者が書くところ）も、レビューが通ったあとの確かめ方（curl など）は Claude が実行して、結果を見せる。期待する結果と違えば、Claude が原因を説明する。
- `,,` や `;;` のような、`tsc` が止まるだけの書き間違い（中身の判断がいらないもの）は、Claude が直して何を直したかを伝える。

## 理由
- 学習者の言葉：「curl の検証もそっちに任せたいな」。時間を優先する進め方（D-0030）の続き。
- curl のコマンドを写して実行するだけの作業は、学習の中心ではない。★ で大事なのは、書くことと、レビューで指摘されたことを直すこと。

## 却下した案
- これまでどおり学習者が curl を実行する：時間がかかる。
