# D-0013 外側の push も Claude が行う

日付: 2026-10-13
置き換える決定: D-0005（「push はしない」の部分。外側のコミットを Claude が行う部分と、`app/` は学習者が行う部分はそのまま）

## 決定
- 外側のリポジトリは GitHub の Private リポジトリ `Miyamura-rq/todo-app-remote` に push する（D-0012）。
- Claude は外側をコミットしたら、続けて push する。
- セッションの始めに、Claude が外側を pull してから作業する。
- `app/` のコミットと push は、これまでどおり学習者が行う。

## 理由
- 外側のコミットはすでに Claude が行っている（D-0005）。push まで続けて行えば、会社 PC と自宅の Mac のどちらでも、最新の記録から始められる。
- コミットと push を分けると、push を忘れたまま PC を替えて、記録が食い違うおそれがある。

## 却下した案
- 学習者が外側を push する: git の練習は `app/` で十分にでき、外側の push を忘れると引き継ぎが崩れる。
- セッションの終わりにまとめて push する: セッションが途中で切れたときに push されない。
