# D-0017 動作確認のコマンドは、Claude が毎回そのまま実行できる形で書く

日付: 2026-10-13

## 決定
- curl など、動作確認に使うコマンドは、確認を頼むたびに Claude がそのまま実行できる形（id などの値も入れた形）で書く。
- 前に示したコマンドでも、「前回のもの」と省略せず、もう一度書く。

## 理由
- 学習者から「curl での確認のとき、面倒だから毎回コマンドを書いておいて」と希望があった。
- 確認のたびにコマンドを探したり組み立てたりする時間を、確認の結果を考える時間に回せる。
- curl の書き方そのものは、ステップ5の学ぶ目的（サーバーと API の仕組み）の中心ではない。

## 却下した案
- 早見表に curl の書き方をまとめて、学習者が組み立てる: 毎回の手間は減らないため。早見表には別途まとめる。
