# D-0004 作成物は app/ に置き、app/ だけを別リポジトリとして GitHub に push する

日付: 2026-10-01

## 決定
- `todo-app/` 直下に `app/` を作り、アプリのコードはすべてその中に置く。
- `app/` の中で `git init` し、`app/` 専用のリポジトリにする。GitHub（`Miyamura-rq` 個人の Private リポジトリ `todo-app`）に push するのはこのリポジトリだけ。
- 外側の `todo-app/` のリポジトリ（CLAUDE.md、STATUS.md、docs/ など対話と学習の記録）はローカルだけで管理し、push しない。外側の `.gitignore` に `app/` を追加する。

## 理由
- 学習者は Claude との対話の記録を共有する予定がない。作成物だけを GitHub に置きたい。
- 作成物と記録を同じ `todo-app/` の下に置くことで、Claude が作業中に CLAUDE.md や学習状況を参照しやすい。

## 却下した案
- 今のリポジトリのまま docs などを .gitignore で除外する: すでにコミットした記録は履歴に残るので、push すると GitHub に送られてしまう。
- `todo-app/` の外に別フォルダを作る: Claude が CLAUDE.md や学習状況を参照しにくくなる。
