# D-0008 ToDo の一覧はリストで作り、完了はチェックで残す

日付: 2026-10-06

## 決定
- ToDo の一覧は `<ul>` / `<li>` で作る。
- 完了はチェックボックスで切り替え、完了した ToDo も一覧に残す。消すときは別の削除ボタンを使う。
- そのため、ToDo は「完了したか」の状態を持つ（ステップ6で DB に列を作る）。

## 理由
- 学習者から「表（中身／期限／完了ボタン）のほうがよいのでは」「完了したら消えるのが多いのでは」と提案があり、比べたうえで学習者が選んだ。
- リスト：多くの ToDo アプリと同じ形で、スマホの狭い画面でも崩れにくい。列をそろえたい場合は CSS で対応できる。
- チェックで残す：やったことが見え、押し間違えても戻せる。

## 却下した案
- 表（`<table>`）: 列の見出しがつく利点はあるが、狭い画面で横にはみ出しやすい。
- 完了ボタンで消す: 作るものは少ないが、完了の記録が残らず、押し間違いを戻せない。
