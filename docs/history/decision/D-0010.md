# D-0010 実装の書き方の選択肢は、Claude がおすすめを決めて示す

日付: 2026-10-07

## 決定
D-0002（ヒントとレビューだけを行う）に、次の補足を加える。D-0002・D-0007 の他の内容は変えない。

- 実装の書き方に複数の選択肢があるとき（例：`filter` か `splice` か）、Claude は選択肢と違いの説明を示したうえで、**どれにするかを決めて理由とともに示す**。学習者に選ばせたままにしない。
- 選択肢の表と説明はこれまでどおり示す（他の書き方を知ること自体が学習になるため）。
- 学習者が自分で選びたいときは、そちらを優先する。
- アプリの仕様や見た目の好み（何を作るか）は、これまでどおり学習者が決める。

## 理由
- 3-5 で ToDo の削除に `filter` と `splice` のどちらを使うか尋ねたところ、学習者から「開発経験がないため、どちらが一般的か判断できない。ある程度判断してもらえると助かる。選択肢の提示と説明はこのままで」と要望があった。
- 一般的かどうかは経験がないと判断できず、選ばせても考える力にはつながりにくい。

## 却下した案
- これまでどおり学習者に選ばせる：判断の材料がなく、止まってしまうため。
- 選択肢を示さず Claude の決めたものだけ示す：他の書き方を知る機会がなくなるため（学習者の要望）。
