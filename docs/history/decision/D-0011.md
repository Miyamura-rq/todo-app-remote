# D-0011 TypeScript は src/ に書き、public/ に変換する。変換した JS は git に入れない

日付: 2026-10-09

## 決定
- 書くファイルは `app/src/main.ts`。`tsc` で `app/public/main.js` に変換する（`tsconfig.json` の `rootDir: "src"`、`outDir: "public"`）
- `public/main.js` は `.gitignore` に入れる。変換は `npm run build`（`package.json` の scripts）
- `tsconfig.json` は `tsc --init` を使わず、ブラウザ向けの最小の設定を手で書く（`strict: true`、`lib` に `dom`）

## 理由
- 書くファイル（src）とブラウザに渡すファイル（public）を分けると、何を直せばよいかがはっきりする
- 作り直せるものは git に入れない（`node_modules/` と同じ考え方）。`main.ts` と `main.js` の中身がずれる心配がない
- 公開（ステップ7）では、公開先で `npm run build` して作る形になる
- `tsc --init` の設定は Node.js 向け（`module: nodenext` など）で、そのままだとブラウザで動かない JS が出る

## 却下した案
- B：A と同じで、`public/main.js` も git に入れる：GitHub でそのまま動くが、変換忘れで `main.ts` とずれる
- C：`public/` に `main.ts` と `main.js` を並べる：ブラウザに見せる場所に不要な `.ts` が混ざる
