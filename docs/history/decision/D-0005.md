# D-0005 外側（todo-app/）のコミットは Claude が行う

日付: 2026-10-01

## 決定
- 外側の `todo-app/` リポジトリ（CLAUDE.md、STATUS.md、docs/、practice/ など）は、Claude が進捗や決定を記録するたびにコミットする。push はしない（D-0004）。
- `app/` のコミットと push は、これまでどおり学習者が自分の手で行う。

## 理由
- 外側は記録のほとんどを Claude が書いており、学習者が手で変更する場面が少ない。毎回コミットするのは手間に見合わない。
- git の練習は、本番の `app/` で十分にできる。
- 外側の git は残しておくことで、記録を誤って消したり上書きしたりしたときに戻せる。

## 却下した案
- 外側の git をやめる（`.git` を削除）: 社内ガイドの「1フォルダ = 1リポジトリ」には合うが、記録を誤って上書きしたときに戻せなくなる。
- 外側はコミットしないまま放置する: 未コミットのものが溜まり、見通しが悪くなる。
