# D-0033 ステップ9（Issue #4）にタグの表と API も含める

日付: 2026-11-01
置き換える決定: D-0032（「ステップ9 はタグのない main から始める」の部分）

## 決定
- ステップ9 の Drizzle への置き換えに、ステップ8 のタグ（`tags`・`todo_tag`、タグの API、付け外し、作るときの `tagIds` とトランザクション）も含める。
- 進め方：`feature/4-drizzle` に `feature/1-tags-search` の server.ts のタグ部分を取り込み、`schema.ts` に2つの表（2つの列の外部キー、組の主キー、`todos` の `UNIQUE (id, user_id)`）を足して generate する。トランザクションは `db.transaction`。
- PR が Issue #4 の範囲（表3つ）を超えることは、学習者がメンターに伝える。

## 理由
- 学習者の言葉：「残したい」。
- マイグレーションがあるので、表を足しても作り直しは要らない。

## 却下した案
- #7 のあとで新しい構成の上に作り直す：学習者が今残すことを選んだ。増える時間は 1.5〜2時間。
