# D-0006 ToDo に期限をつける（リマインドは余裕があれば後で）

日付: 2026-10-06

## 決定
- ToDo に期限をつける。入力欄は `<input type="date">`。
- やるのは「期限の入力・保存・表示」まで。ステップ3で一覧に表示し、ステップ6で DB に期限の列を作る。
- リマインド（通知）は学習の範囲に入れない。ステップ8まで終えて余裕があれば、追加でやる。

## 理由
- 学習者が 2-2 の画面作りで、自分から期限の入力欄を加えた。`app/README.md` の「リマインド」にもつながる。
- 入力・表示・保存だけなら、各ステップの学習内容の延長で扱える。
- 通知には定期的に動く仕組みや通知の送り先が必要で、D-0001 の学習範囲を大きく超える。

## 却下した案
- 期限をつけない: 学習者がつけたいと考えたため。
- リマインドまで学習範囲に入れる: 2026-10-06 中にステップ8まで進めたいという予定に収まらないため。
