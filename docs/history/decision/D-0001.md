# D-0001 学習プランを9ステップ（0〜8）で進める

日付: 2026-10-01

## 決定
このプロジェクトは、Web アプリ開発の流れと基礎知識を身につけるための学習として進める。次の順で、1ステップずつ新しいことを足していく。期間は定めない。

| ステップ | 学ぶこと | ゴール |
|---|---|---|
| 0. 道具の準備 | ターミナル、エディタ、git / GitHub、Node.js | 自分の手で GitHub に push できる |
| 1. Web の仕組み | ブラウザとサーバ、URL、HTTP | ページが表示されるまでの流れを説明できる |
| 2. HTML / CSS | 画面の骨組みと見た目 | ToDo の画面（見た目だけ） |
| 3. JavaScript | 基本文法と画面の操作 | 画面で ToDo を追加・削除できる（再読み込みで消える） |
| 4. TypeScript | 型とは何か、型の利点 | ステップ3のコードを TypeScript に書き換える |
| 5. サーバ | Node.js + Express、API | サーバとやりとりして ToDo を扱う |
| 6. データベース | SQL、PostgreSQL | 再読み込みしても消えない（ローカルで完成） |
| 7. 公開 | ホスティング、環境変数 | インターネット上でアクセスできる |
| 8. 品質 | 入力チェック、エラー処理、テスト、セキュリティ | 壊れにくく、安全にする |

- 各ステップの細かい学習内容（何を、どの順で、何ができたら次へ進むか）は、そのステップの始めにメンター（Claude）が作る。
- 各ステップで、その層の技術の選定基準と、他にどんな言語・手段があるかも教える。
- 「web 上で動く」の意味（公開先の条件など）は、ステップ7に入る前に改めて確認する。

## 理由
- 学習者は Python を少し触った程度で、Web の仕組みの知識はまだない。土台から1つずつ積み上げる順番にした。
- TypeScript は JavaScript に型を足したものなので、先に JavaScript を学ぶ。
- データが消える状態（ステップ3）を先に体験すると、サーバやデータベースが必要な理由を実感できる。

## 却下した案
- ステップ9「発展（GitHub での PR などチーム開発の流れ）」: 今は不要と学習者が判断したため外した。必要になったら追加する。
