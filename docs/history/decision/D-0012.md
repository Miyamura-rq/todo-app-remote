# D-0012 外側も GitHub の Private リポジトリに push し、会社 PC と自宅の Mac で引き継ぐ

日付: 2026-10-13
置き換える決定: D-0004（外側をローカルだけで管理し、push しない部分。`app/` を別リポジトリにする部分はそのまま）

## 決定
- 外側の `todo-app/`（CLAUDE.md、STATUS.md、docs/、practice/）も、GitHub の Private リポジトリに push する。
- `app/` はこれまでどおり別リポジトリ（`Miyamura-rq/todo-app`）。外側の `.gitignore` で `app/` を除外したままにする。
- 自宅では、外側を clone してから、その中に `app/` を clone する。
- Claude の会話履歴（`~/.claude/projects/`）は持っていかない。引き継ぎは STATUS.md と docs/history で行う。
- Claude の共通設定（`~/.claude/CLAUDE.md`、`~/.claude/skills/`）は自宅の Mac にもコピーする。

## 理由
- 会社のノート PC と自宅の Mac の両方で学習を続けたい。
- `app/` で使っている git と GitHub の流れをそのまま使え、「pull してから始めて、push して終わる」の同じ習慣で回せる。
- 履歴が残るので、どちらの PC の内容が新しいか迷わない。
- Private リポジトリなので、対話と学習の記録を他人に共有しないという D-0004 の理由は守れる。
- 会話履歴は大きく（約 25MB）、PC ごとのパスに結びついている。必要な経緯は docs/history に残しているので持っていく必要がない。

## 却下した案
- Remote Control / クラウドセッション: 会社 PC を起動したままにする必要があり、自分で手を動かす学習に向かない。
- USB メモリや `git bundle` で運ぶ: 毎回手作業になり、どちらが新しいか分からなくなりがち。
- iCloud / Google Drive で同期する: 同期の途中で `.git` が壊れることがあり、`node_modules/` も重い。
- 会社のノート PC を持ち帰る: 自宅の Mac で作業したい。
