# D-0016 新しい文法や関数は、Claude が書き方の型を先に示す

日付: 2026-10-13

## 決定
- 新しい文法・関数・コマンド（`async` / `await`、`fetch` など）を使う課題では、Claude が先に「書き方の型」（形、引数、戻り値、型の書き方、注意点）をまとめて示す。
- 型は、`○○` のような置き換える場所を示した一般形や、課題とは別の例で示す。課題そのものの答えは書かない（D-0002 は変わらない）。
- 「何を作るか（手順）」と「どう書くか（書き方の型）」を分けて示し、学習者は書き方の型を見ながら手順を組み立てる。

## 理由
- 学習者から「`async` などの新しいものがある場合は、必要な情報をそちらで提供してほしい」と希望があった。
- 5-1〜5-3 では、`express()`、`res.json`、パスの文字列、`/api` の意味など、説明が足りないまま課題に進み、詰まることが多かった。
- 新しい書き方は、調べても分からない（何を調べればよいか分からない）ことが多く、ヒントを待つより先に示したほうが、考えるべきところ（組み立て）に時間を使える。
- D-0007（暗記するだけの軽い知識は答えを教える）を、文法・関数の書き方にも広げたもの。

## 却下した案
- 課題の答えのコードをそのまま示す: 自分で組み立てる機会がなくなるため（D-0002）。
- これまでどおりヒントで少しずつ出す: 新しい書き方そのものはヒントから推測できず、時間がかかるため。
