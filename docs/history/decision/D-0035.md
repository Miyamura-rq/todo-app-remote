# D-0035 だれが書くかは、その日の学習者の時間で決める。Claude は部分ごとに重要度（高・中・低）を示す

日付: 2026-11-02
補足する決定: D-0030（ふだんは Claude が多くを書く）

## 決定
- 時間がある日は、学習者が多くのコードを書く。学習者は、一部を Claude に任せてもよい。
- Claude は項目を始めるとき、部分ごとに重要度（高・中・低）を示す。高は仕組みの理解に関わる部分で、なるべく学習者が書くか、Claude が書いたあとで詳しく解説する。低は作業だけの部分（雛形を作る、ファイルを消すなど）で、任されたら Claude が書く。
- 学習者が書く部分は、これまでの課題の出し方（D-0021・D-0028）とレビュー（D-0023）で進め、確かめ方は Claude が実行する（D-0034）。
- 時間がない日は D-0030 のとおり、Claude が多くを書いて ★ だけ学習者が書く。

## 理由
- 学習者の言葉：「今日やや時間あるから、大体のコードはこっちで頑張って作ろうかな。一部任せたりしながらやるかも。重要度が高い部分は適宜教えて」。

## 却下した案
- D-0030 のまま Claude が多くを書く：時間がある日は、自分で書いた方が身につく。
