# D-0019 PC を切り替えるときは、app/ を途中でも push し、Claude が途中の位置まで記録する

日付: 2026-10-14

## 決定
会社の PC と自宅の Mac（D-0012）など、PC を切り替えて続けるときは次のようにする。

- 学習者：`app/` を課題の途中でもコミットして push する（例：「7-2 途中：ログイン画面の HTML まで」）。始めるときは `app/` で `git pull` する。
- Claude：学習者が「今日はここまで」「PC を切り替えます」と言ったら、どの課題の、どこまでやったか、次に何をするかを STATUS.md に書き、外側を push する。
- 言い忘れて終わった場合は、次の PC で Claude が git の履歴と `app/` のコードを見て、途中の位置を確かめてから再開する。
- git に入っていないもの（`node_modules/`、`public/main.js`、`dist/`、`.env`、DB とそのデータ）は PC ごとに作り直す。ToDo のデータは引き継がれない。
- Windows でも動かせる。Postgres.app の代わりに PostgreSQL 公式のインストーラーを使い、PATH と `.env` の接続文字列（ユーザー `postgres` とパスワード）を合わせる。改行コード（CRLF / LF）の違いに注意する。

## 理由
- これまでは課題が終わったときに記録していたので、課題の途中で止めると、もう一方の PC で途中の位置が分からなかった。
- push していない変更は、もう一方の PC からは見えない。

## 却下した案
- 課題の区切りまで終えてから切り替える: 時間の都合で途中で止めることがあり、守れない。
