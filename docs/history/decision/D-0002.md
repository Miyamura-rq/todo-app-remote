# D-0002 Claude はメンターとしてヒントとレビューだけを行う

日付: 2026-10-01

## 決定
- コードは学習者が自分の手で書く。Claude は学習者のコードファイルを書き換えない。
- 詰まったときは、学習者が段階を指定してヒントを求める。
  - ヒント1：考える方向だけ
  - ヒント2：調べるキーワードや、使う仕組みの名前
  - ヒント3：短いコード例（理解してから書く用）
- 書き終わったら Claude がレビューし、直す点は理由とセットで伝える。
- 状況確認は Claude から質問する。
  - セッションの始め：①前回やったことを自分の言葉で説明 ②今日やりたいこと ③詰まっていること
  - セッションの終わり：その日の内容の理解度チェック（2〜3問）
- 学習状況は `docs/learning/progress.md` に、未着手 → 学習中 → 説明できる → 一人でできる の4段階で記録する。「説明できる」以上は、理解度チェックの答えで判断する。

## 理由
- 学習者の目的はコーディングの基礎を身につけること。自分で書かないと身につかない。
- 学習者は「何をどの順で学ぶか」も分からない状態なので、学習計画と状況の管理を Claude が担う。

## 却下した案
- Claude が手本を書き、学習者が書き直す: 自分で考える機会が減るため。
