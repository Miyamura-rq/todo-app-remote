# D-0003 技術スタックは TypeScript + Node.js（Express）+ PostgreSQL にする

日付: 2026-10-01

## 決定
| 層 | 使うもの |
|---|---|
| フロントエンド | HTML / CSS / TypeScript（React などのフレームワークは使わない） |
| バックエンド | Node.js + Express（TypeScript で書く） |
| データベース | PostgreSQL（細かい選び方はステップ6で決める） |
| ホスティング | ステップ7で決める |

## 理由
- 指定された条件：TypeScript を使う、web 上で動く、何らかのデータベースを使う。
- 画面とサーバを同じ言語（TypeScript）で書けるので、覚える言語が1つで済む。
- 最初はフレームワークを使わず、Web の土台から理解する。
- Express は日本語の資料が多く、初学者が調べやすい。
- PostgreSQL は実務で広く使われている。
- ホスティングは会社の決まりがあるかもしれないため、ステップ7で確認してから決める。

## 却下した案
- Python + Flask + SQLite: TypeScript を使う指定があるため。
- Next.js などのフルスタックフレームワーク: 便利だが仕組みが隠れるため、基礎の学習には向かない。
- Hono（Express の代わり）: TypeScript と相性がよいが、初学者向けの資料は Express の方が多い。
